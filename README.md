# Infinity Root Portal

The `INFINITY` repository is the main entry point for the `www-infinity4` project network.

## Purpose

This root does not copy every repository into one oversized codebase. It provides a live directory, shared architecture, standards, creation contracts, value-type boundaries, and integration paths while every project keeps its own source history and deployment.

## Current build

- Responsive blue-purple root website
- Live GitHub repository discovery
- Search and automatic project grouping
- Direct links to every repository
- Architecture and provider-neutral AI-gateway documentation
- No API secrets stored in browser code
- **Infinity AI Token Studio** for the universal small Star mark, system-need ranking, Product Tokens, named Star Blueprint versions, Avatar Coin requirements, charts, and local prototype ledgers
- **Infinity Economy System Map** connecting every website, ledger, value type, input, output, and protection rule
- **Good Bee · Infinity Living** for voluntary accessible travel, relocation, housing, support, and NFC benefit packages
- **Infinity Store Cards** for cards, stores, benefits, drops, physical collectibles, provenance, and fulfillment
- **Infinity Reciprocal Clearing Loop** for retiring Store Claims before issuing general Infinity units
- **Infinity AI Wallet Orchestrator** for Star Blueprints, Product Tokens, Avatar Coins, hotel nights, physical-metal access, NFC discounts, products, businesses, ads, work, and user decisions
- **Infinity Coin Planner** for global business discovery, local-first sourcing, bulk contracts, destination staging, transparent package funding, and fulfillment
- **Alien Radio Star and Avatar integration** maintained on an independent Alien Radio branch and draft pull request

## Infinity AI Token Studio

Open [`good-bee/token-studio.html`](good-bee/token-studio.html).

The Token Studio establishes one platform-wide conversion language:

```text
Human idea or working system
→ Star Blueprint ⭐
→ Product Token
→ verified capacity and funding
→ Store Claim
→ fulfillment or permitted clearing
```

For an operating identity such as a radio station or business, the branch may also require:

```text
Verified-use rule
→ Avatar Coin
→ one Avatar Coin locked to one active identity
```

### Universal small Star standard

Every convertible object may receive the same subtle upper-right Star mark:

- 15 × 15 pixels;
- identical location and interaction behavior;
- partial opacity until hover or keyboard focus;
- opens the selected object in the Token Studio;
- means create, edit, version, convert, connect, or inspect ancestry;
- does not mean favorite, rating, endorsement, verification, ownership, funding, or guaranteed value.

### Product Need Engine

The visible planning score is:

```text
System demand × 35%
+ scarcity × 25%
+ human usefulness × 20%
+ production readiness × 10%
+ local capacity × 10%
```

The page ranks current product needs, identifies the weakest factor, draws need and supply charts, calculates a minimum Product Token quantity, and saves named child versions without overwriting their parents.

Seed modules currently include:

- Alien Radio station system;
- hotel nights;
- accessible home components;
- Good Bee destination packages;
- business-plan coins;
- AI-matched work roles;
- Store Card offers.

## Alien Radio Star and Avatar system

The working `www-infinity4/Alien-Radio` repository remains separate from the Infinity root.


- `star-stage.css` subtle Star marks and the creation-stage interface;

The Alien Radio prototype rule is:

```text
Another verified user actively uses the creator's station design
for 24 continuous qualified hours
→ one Avatar Coin is produced
→ one Avatar Coin is locked to one active radio-station identity
```

Creator self-use, hidden tabs, stopped playback, bots, and clearly labeled demonstration time do not qualify for a production Avatar Coin. ## Infinity Coin Planner

Open [`good-bee/coin-planner.html`](good-bee/coin-planner.html) for the global-local package engine.

Coin Planner:

- consumes defined Product Token needs;
- builds country, locality, destination, and business records from permitted official, licensed, open, merchant-direct, industry, and community sources;
- normalizes and deduplicates listings;
- verifies merchant control, payout, capacity, accessibility, contracts, and licenses;
- sources hotels, meals, transportation, products, activities, and support locally before importing;
- requests bulk and off-peak contracts;
- forecasts likely destination demand;
- stages appropriate durable inventory;
- combines separate Store Claims into one understandable package;
- separates public retail-equivalent benchmark from actual contracted cost;
- shows traveler, sponsor, program, and Infinity-pool funding separately;
- blocks package publication while an unfunded gap remains;
- settles each provider only after verified fulfillment.

The included demonstration shows how a $1,000 retail-equivalent benchmark could be offered for 100 Infinity units only when real contracts and disclosed funding cover the actual package cost. It is not a guaranteed price or active offer.

## Prototype boundary

The repository does not currently operate housing, healthcare, travel, payments, prepaid accounts, currency, cryptocurrency, Avatar Coin identity verification, metal sales, auctions, lending, government benefits, merchant settlement, or guaranteed packages. All displayed Star versions, Product Tokens, Avatar Coins, balances, prices, discounts, inventory, funding, cards, units, metals, businesses, and packages are demonstrations until verified contracts and qualified protected systems exist.

## Local AI runtime

The repository also includes a local, standard-library AI runtime for the wider Infinity research system.

Start the standard-library runtime with:

```bash
python ai-runtime/server.py
```

Browser access to the loopback runtime is deliberately opt-in. Configure one exact HTTPS
application origin; the wildcard default will never receive a private-network grant:

```bash
INFINITY_AI_ALLOW_ORIGIN=https://your-app.example \
INFINITY_AI_ALLOW_PRIVATE_NETWORK=1 \
python ai-runtime/server.py
```

Modern browsers may also ask the user for local-network permission. The response header is only
one part of that browser security flow; it does not bypass the user's permission choice. Keep the
service bound to loopback unless remote access is intentionally secured.

Run the header contract tests with:

```bash
python ai-runtime/test_server.py
```
