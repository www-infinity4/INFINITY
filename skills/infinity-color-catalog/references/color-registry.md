# Color Registry

| Color | Operation | Core rule |
|---|---|---|
| Yellow | Extraction | Preserve selected source word for word; no interpretation or code |
| Blue | Import | Bring approved material into a named destination and record a receipt |
| Green | Engineering | Implement or create original work and verify the result |
| Red | Reroute | Copy or redirect linked material to a known destination without losing ancestry |
| Orange | CEO decision | Record a strategic choice, reason, owner, and next operation |
| Purple | Assimilation | Combine compatible inputs while recording corrections, interfaces, and gaps |
| Pink | Investigate | Examine an unknown, anomaly, unverified claim, or blocker using evidence |

Useful relationships include Yellow plus Blue producing Green, Yellow plus Red producing Orange, and Blue plus Red producing Purple. These are descriptive relationships, not mandatory transitions.

Keep scientific hypotheses distinct from established findings. A conceptual color analogy remains Pink or Purple until it produces defined quantities, testable predictions, measurements, and reproducible verification.
