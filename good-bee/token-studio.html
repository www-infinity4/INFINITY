Token wiring

Different token types perform different jobs.

01

Star Blueprint ⭐

Editable, named, attributable version with parent history. It preserves creation and can be changed without erasing the earlier design.

02

Product Token

Defines the exact product, service, component, station, work role, capacity, tests, rights, and production quantity the system needs.

03

Avatar Coin

Required only for distinct operating identities such as radio stations or businesses. A verified-use rule produces it; one coin locks to one active identity.

04

Store Claim

Created only after capacity, funding, provider, restrictions, delivery, refund, and dispute rules are verified.

05

AI Wallet

Shows what can be used, saved, combined, earned, converted, approved, or disputed without collapsing every value type into one number.

06

Clearing

When permitted, locks and retires a specific Store Claim before replacement Infinity units are issued.
