01 · Research findings

Waveform and frequency measurements

Browser AnalyserNode can provide time-domain PCM and frequency-domain bins. The studio measures RMS, sample peak and strongest FFT bin from a user-selected local audio file. These measurements do not identify a speaker, infer thoughts, or establish mood.

MDN: float time-domain data · MDN: frequency-domain bins

Audio processing and limits

The Web Audio API allows a local media element to feed a graph of gains, filters and dynamics compression. The prototype's original setting is a dry reference mix. Its optional speech, phone and night profiles use ordinary browser DSP nodes—not automatic speech separation, machine-generated sound, or guaranteed lossless restoration.

Dynamics processors introduce processing latency. Professional programme loudness and true-peak measurement use methods such as ITU-R BS.1770, which this early RMS/sample-peak analyzer has not implemented.

MDN: media element audio graph · W3C: Web Audio specification · ITU-R: loudness and true-peak standard

Google Wave precedent

The historical Google Wave and Apache Wave projects use editable conversation units called blips and describe collaboration, transformations and federation. Wave Studio implements a local parent-linked blip notebook only; it does not currently implement operational transformation, conflict-free replication, WebSocket rooms, federation or cross-device synchronization.

Apache Wave: protocol specifications · Apache Wave: federation specification

Omni Gemini and Solidify integration

Events and project candidates are local, validated JSON records for review. A candidate is not a validated release, a bot execution receipt, a signed permission grant, or an authorization to publish. Full agent orchestration remains in the existing Bubbles and Solidify systems.

03 · Separate scientific research lane

The atmospheric matter-assembly and gamma-ray ideas belong in a distinct, explicitly experimental research record. This public audio page does not reproduce confidential chamber layouts or give instructions for using radioactive materials. Current evidence for DNA amplification involves an existing template, primers, nucleotides and polymerase; the audio engine provides no biological manufacturing capability.
